## 店铺毛利

`收入 - ((Q / 0.8) × 合同折扣) - 物流`

合同折扣来自 TTL 每个店铺的“按照0.52/0.65折计算-毛利”行。

## 数据源隔离

`legacy_workbook.py` 负责将原 Excel 转成标准数据库表；`legacy_logic.py` 只负责规则计算。旺店通 API 后续替换数据源时，原则上不修改 `legacy_logic.py`。
