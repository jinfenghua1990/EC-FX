# V0.8.1 品牌返利按渠道配置

## 原则

品牌返利的计算基数仍来自标准化采购单，但规则匹配顺序调整为：

1. 采购渠道（第一维度，必需）
2. 品牌（可选二级筛选）
3. 返利组成项（同一渠道可叠加）
4. 生效月份
5. 优先级

## 网页交互

用户选择渠道后，只需要填写返利组成项、比例、计算基数和生效期。比例按百分比输入，例如 `5` 表示 `5%`。

品牌留空或 `*` 表示该渠道所有品牌；如某品牌有特殊政策，再新增品牌专属规则。

## 计算

`返利金额 = 采购基数 × 返利比例 × 附加系数`

返利比例、附加系数、组成项和有效期都由网页维护，不写死在代码中。

月度计算会输出：总返利、各渠道返利、各渠道组成项、未匹配采购记录。
