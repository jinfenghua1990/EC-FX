### 关于 TAB 的技术选型说明
采用 **外壳 + iframe 多标签**，不用 SPA 重写。理由：

- 现有 6 个页面各自是独立 HTML + 内联脚本，改造成 SPA 等于重写全部前端，风险极高（无 git 兜底）；
- iframe 天然满足"切 TAB 不销毁页面"：搜索词、筛选、页码、排序、滚动位置、已打开记录全部保留，不需要给每个页面单独做状态序列化；
- 一套系统、一套数据源，不存在"复制多个业务系统"。

代价（必须承认）：浏览器前进后退需要外壳层接管；dirty 提示需要子页面上报 `postMessage`；iframe 内页面自带的 `location.href` 跳转已改为 `fxNav()`，遗漏的会变成 iframe 内跳转（不影响功能，但 TAB 标题会滞后）。
